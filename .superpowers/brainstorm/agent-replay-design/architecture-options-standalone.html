SmartPages Agent 执行架构

本地 Agent 调用 SmartPages，依据结构化流程操作用户当前浏览器。

推荐 A

MCP + Native Messaging

Agent → MCP Server → Native Host → SmartPages 扩展 → 网页

✓ 边界清晰；可适配多种 Agent；扩展掌握真实标签页和登录态。

△ 初次安装需要注册本地桥接程序。

方案 B

MCP + WebSocket

Agent → localhost 服务 ⇄ SmartPages 扩展 → 网页

✓ 原型开发和调试直观。

△ 需要处理端口暴露、来源认证、重连及商店审核风险。

方案 C

导出 Playwright

SmartPages → 流程脚本 → Agent / Playwright → 浏览器

✓ 最快得到可执行原型。

△ Agent 绕过插件，难复用用户当前浏览器会话，偏离产品定位。

建议：选择 A。MCP Server 暴露 Agent 工具；Native Host 只负责可信传输；扩展负责元素定位、动作执行、逐步确认和日志。JSON 流程作为稳定契约。
