写操作说明，最机械的一步往往发生在操作结束以后：再翻一遍流程，把截图、步骤和说明重新拼起来。

SmartPages 是一个开源的 Chrome / Edge 扩展，想把这段重复劳动缩短一点。

使用方式很直接：

① 打开录制，按平时的方式完成网页操作
② 自动记录点击、输入、页面跳转和关键截图
③ 选择要生成的内容：用户指南、教程、测试用例或 Bug 报告
④ 检查并修改结果，再导出成 Markdown、HTML、Word、PDF、图片或 ZIP

模型也不锁死。可以配置 OpenAI、Gemini、Claude、DeepSeek、Kimi、通义千问等服务，也支持其他兼容接口。API Key、Base URL 和模型都由自己选择。

生成出来的内容不是一份不能动的“成品”。可以继续编辑正文或 Markdown，用 AI 再优化，也可以保留不同版本，确认后再导出。

有两点使用前值得注意：

• API Key 保存在 Chrome Storage，不会写进项目仓库
• 录制时仍要避开密码、验证码、Token 等敏感信息；只有主动开启图片输入后，截图才会发送给所配置的多模态模型

如果你经常整理产品操作手册、内部 SOP、测试步骤或 Bug 复现过程，可以试试这个思路。
