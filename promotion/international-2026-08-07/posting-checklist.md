# International Posting Checklist

- [ ] Before every submission, ask Codex to optimize the exact platform draft with the HumanWriting skill. Do not reuse an approval after editing the copy.
- [ ] Hacker News: confirm account login; review the maker-written first comment; submit one Show HN link; never solicit votes.
- [ ] Reddit: select exactly one community; read its current self-promotion rules; adapt the title/flair; submit only after review.
- [ ] Product Hunt: confirm personal account onboarding; create a launch draft; add maker profile and assets; do not schedule yet.
- [ ] DEV Community: confirm login; upload a cover; paste Markdown; keep `published: false`; save as draft.

Final checks:

- Verify the HumanWriting review is current. API scripts must reject a draft whose content no longer matches its review receipt.
- Confirm the account/page identity shown by each platform.
- Verify every link and uploaded asset.
- Keep platform-specific wording; do not mass-post identical copy.
- Stop before final publication or launch scheduling unless the user explicitly approves that exact platform.
