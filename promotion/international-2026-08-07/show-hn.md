I built SmartPages because writing product guides and bug reproduction steps often took longer than performing the workflow itself.

It is a Chrome/Edge extension that records clicks, input, navigation, and step screenshots, then uses a model you configure to generate an editable document. It works with OpenAI-compatible APIs and Anthropic, and exports Markdown, HTML, Word, PDF, ZIP, and images.

The extension keeps provider configuration in browser storage. Recorded data is sent only when generating a document, and screenshots are included only when image input is explicitly enabled. The repository also includes an experimental local workflow format and MCP/Agent Bridge.

I would especially value feedback on the recording UX, generated-document quality, and the local workflow format.
