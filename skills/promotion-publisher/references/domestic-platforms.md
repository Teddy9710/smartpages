# Domestic promotion platforms

Use this reference only for channel-specific writing and publishing constraints. Apply the core workflow in `SKILL.md` to every platform.

## V2EX

- Best for: maker launches, open-source feedback, technical peers.
- Tone: sincere, concise, developer-to-developer.
- Include: why it exists, what it does, demo GIF, repository link, and a concrete feedback question.
- Likely nodes: 分享创造, 程序员, Chrome, 开源软件. Verify the current node before posting.
- Avoid: pure advertising, vote requests, repeated cross-posts.

## Juejin

- Best for: technical write-ups, implementation notes, AI tooling, browser extension development.
- Tone: structured technical article with real implementation detail.
- Suggested tags: 前端, Chrome 插件, AI, 开源, 效率工具.

## CSDN

- Best for: searchable tutorials and long-tail discovery.
- Tone: practical guide.
- Include: installation, configuration, usage, common issues, and repository link.
- Suggested tags: Chrome 插件, AI, 文档生成, 自动化测试, 开源项目.

## cnblogs

- Best for: engineering narratives and project logs.
- Include: project goal, architecture, difficult implementation choices, use cases, limitations, and next steps.

## Zhihu

- Best for: problem-led articles or answers.
- Tone: analytical and restrained.
- Useful angles: 如何降低操作文档编写成本; 是否有开源的 Scribe/Tango 替代方案.
- Explain tradeoffs and current limitations; avoid exaggerated claims.

## Jike

- Best for: short maker updates.
- Use one or two personal paragraphs, one GIF or screenshot, the project link, and one feedback request.

## WeChat Official Account

- Best for: polished Chinese launch articles.
- Include: problem, demo, use cases, installation, privacy/model configuration, and roadmap.
- Preview formatting and media on mobile before publishing.

## Xiaohongshu

Use the dedicated `xiaohongshu.md` adapter. It adds HumanWriting receipt enforcement, local-media validation, preview-first browser staging, explicit release confirmation, and publication verification.
